# dotfiles

Configuración personal de CachyOS: Hyprland, hyprlock/hypridle, Waybar, Rofi, mako, kitty, zsh + Oh My Posh, fastfetch y asociaciones de archivos.

Restaurar en un equipo nuevo:

    git clone <repo> ~/dotfiles
    ~/dotfiles/install.sh

Los archivos se enlazan con symlinks; lo que ya exista se guarda en `~/.dotfiles-backup-*`.
